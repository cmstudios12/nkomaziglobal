NKOMAZI GLOBAL FET COLLEGE — PREMIUM MATCHED WEBSITE

Open index.html to preview. All three pages share unified.css, unified.js, the same navigation, footer, responsive design and icon library.

IMPORTANT: assets/college-mark.svg is a TEMPORARY emblem, not your real college logo. Replace it with your actual logo file and update image paths in the three HTML files. Campus photos are not supplied. The homepage uses external illustrative educational photography, not verified campus images.

Supabase project is set in config.js. To activate applications, run supabase-setup.sql in your Supabase SQL Editor. Create a user in Authentication, then add their UUID to public.admin_users as explained in README.txt. Test application submission and admin access before publishing.

Run via a local development server or HTTPS hosting for reliable operation.
